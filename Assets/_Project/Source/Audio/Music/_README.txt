Nhạc nền - thả file vào đây (nên dùng ogg / mp3, cần loop mượt), đặt đúng tên:

bgm_menu   nhạc ở Main Menu
bgm_game   nhạc lúc chơi

Chuyển menu <-> màn chơi thì nhạc tự mờ dần sang bài kia.
Xong thì chạy Tools/KoreanGame/Audio/Relink Clips trong scene BentoJourney rồi lưu scene.
Âm lượng nhạc chỉnh ở AudioManager (Music Volume, mặc định 0.2).
