Tiếng UI - thả file vào đây (wav / ogg / mp3 đều được), đặt đúng tên:

sfx_click        bấm nút bất kỳ
sfx_tab          đổi tab (menu dưới, danh mục shop)
sfx_popup_open   mở popup Cài đặt
sfx_popup_close  đóng popup Cài đặt
sfx_coin         nhận vàng khi qua màn
sfx_buy          tiêu vàng (mua đồ shop, gợi ý trả phí)
sfx_hint         bấm Gợi ý ra nước đi
sfx_new_dish     popup Món mới (món đặc trưng)
sfx_new_side     thẻ món phụ mới

Xong thì mở scene BentoJourney, chạy Tools/KoreanGame/Audio/Relink Clips rồi lưu scene.
Console sẽ in tên những file còn thiếu. Thiếu file nào thì tiếng đó im, game vẫn chạy bình thường.
Tiếng gameplay (cắt, thả, xoay...) nằm ở Gameplay_SFX, thay file cùng tên là được.
